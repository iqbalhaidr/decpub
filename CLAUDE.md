Saya ditugaskan oleh dosen pembimbing saya untuk melakukan integrasi dari 3 tugas akhir milik kakak tingkat saya (hugo, ciko, roihan) sampai menjadi sebuah sistem yang menyatu. Fokus ciko adalah untuk menghilangkan bias identitas, hugo untuk insentif, dan roihan sebagai framework/sistem publikasi ilmiah secara keseluruhan. Bantu saya untuk mengerjakan integrasi ini, karena nantinya tugas akhir/skripsi saya akan mengembangkan lebih lanjut dari sistem tersebut. Ekspektasi akhir dari sistem terintegrasi adalah sebuah sistem yang jalan yang bisa dicoba masing-masing fungsinya dari mulai awal-akhir (keseluruhan alur). Silakan untuk kamu lakukan adjustment yang diperlukan pada ketiga rancangan tersebut untuk melakukan integrasinya.  Terdapat 3 folder dengan nama Hugo, Ciko, Roihan masing-masing didalamnya memuat laporan tugas akhir dengan format TA_{Hugo/Ciko/Roihan} serta folder kode implementasinya masing-masing, silakan kamu baca dan gunakan sebagai referensi. Beberapa pesan saya ini: 

1. IPFS/Public Off Chain disimulasikan sederhana saja, mungkin hanya layanan/service penyimpanan yang bisa upload file serta search dan download berdasarkan ID yakni hash. berikan interface web super simpel, mungkin cukup html saja dengan form ID untuk search dan download. Sehingga ketika ingin mengganti menjadi IPFS beneran, tidak terlalu sulit.
2. Untuk saat ini gunakan network blockchain sepolia (namun untuk pengetesan boleh disimulasikan saja terlebih dahulu sebelum nantinya di deploy beneran di sepolia)
3. Service/modul QoS (q2, q3) milik hugo cukup disimulasikan sederhana saja, tidak perlu sampai inferensi llm.
4. Integrasikan rancangan milik hugo yang berfokus pada sistem insentif hibrida adaptif.
5. Mekanisme menggunakan escrow pool milik hugo (dimana penulis bayar terlebih dahulu macam APC nya)
6. Untuk zero knowledge proof milik ciko karena belum diimplementasikan, cukup disimulasikan sederhana saja seperti pada saat pembuatan ephemereal account, reviewer/editor, selective disclosure
7. proses pra-pengajuan, pengajuan manuskrip, pengecekkan, penghapusan identitas, penyaringan editorial, pemilihan penelaah, proses telaah, keputusan akhir, pasca publikasi mengikuti rancangan ciko. 
8. Secara umum integrasikan rancangan alur publikasi ciko yakni mekanisme anonimitas triple blind peer review yang berfokus untuk mengurangi bias identitas
9. Integrasikan rancangan milik roihan untuk komplementer kedua rancangan sebelumnya (ciko dan hugo)
10. Gunakan frontend yang paling mature dari ketiga ini (roihan, hugo, ciko), tebakan saya roihan yang paling mature. silakan lakukan adjustment apabila diperlukan. Untuk frontend ini tolong stripdown semua yang bersifat estetik, UI/UX itu bukan prioritas. Saya ingin desain yang sangat basic/plain mungkin (tidak ada dekorasi2, purely mungkin hanya basic tulisan macam website zaman dahulu yang dimana stylenya hanya tulisan saja. seperti  website berkshire hathaway, craiglist, dan lain sebagainya). Karena fokus saya adalah mendemostrasikan alur/flow keseluruhan saja sehingga dengan lebih sedikit distraksi lebih baik, yang penting fungsional.
